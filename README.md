# Money Moves

Money Moves is a DECA Personal Financial Literacy (PMFL) project. It helps students practice everyday money decisions through short lessons and a 12-month financial simulator.

**Website:** <https://shreyaanshp1.github.io/money-moves-pmfl/>

## Run locally

This is a static website with no package installation required. From this folder, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

Learning progress is saved in the browser using local storage. Simulator values are fictional; the project is for financial education, not financial advice.
